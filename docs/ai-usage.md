# [싸피] 잡도리 — AI 활용내역 (제출용 최종본)

> 제출 메일 본문·제출 폼의 'AI 활용내역' 칸에 그대로 붙여넣는다. 모델명 칸은 `.env.local`의 `LLM_MODEL_EXTRACT` / `LLM_MODEL_REASON` 값으로 채운다.

## 1. 서비스 안의 AI (프로덕트 기능)

| 기능 | 사용한 AI·방식 | 입력 | 출력 | 오류·안전 장치 |
|---|---|---|---|---|
| 전형 일정 추출 | Google Gemini API (`LLM_MODEL_EXTRACT`), 구조화 출력 | 사용자가 연 공고 원문 | 단계·날짜 종류(확정/범위/미정)·원문 근거 JSON | Zod 스키마 검증, 근거 문장이 원문에 없으면 '근거 확인 필요' 표시, 같은 공고는 공유 캐시로 1회만 분석 |
| 예상 일정 | 규칙 코드 (LLM 미사용) | 앞 단계 날짜, 공고 문구 | 날짜 미정 단계의 추정 구간 (점점선) | '추정' 라벨, 사용자가 확정해야 실선 |
| 결과 안내 판독 | Gemini API (`LLM_MODEL_EXTRACT`) | 합격·일정 안내 메일 텍스트 | 합격/불합격/일정 안내, 다음 단계 날짜·시각 | 보내기 전 이름·이메일·전화번호 마스킹, 원문 미저장, 변경은 사용자 승인 후 반영 |
| 맞춤 공고 추천 이유 | 점수는 규칙 코드, 이유 문장만 Gemini API (`LLM_MODEL_REASON`) | 관심 직무·지역·자격, 현재 일정 | 추천 이유 한두 문장 | 수락해야만 일정 생성 |
| 충돌 감지 | 규칙 코드 (LLM 미사용) | 캘린더 전체 일정 | 겹침 경고 (확정끼리 강한 경고, 추정 포함 약한 경고) | 판단은 코드로만 |
| 충돌 조정 문구 | 대상은 규칙 코드, 문구만 Gemini API (`LLM_MODEL_REASON`) | 겹친 두 일정 | 채용담당자 문의 문구 / 개인 일정 이동 메모 | 다른 기업명이 들어가면 기본 문구로 대체, 보내기·변경은 사용자가 직접 |

- 연결 방식: OpenAI 호환 Chat Completions 엔드포인트 하나(`src/lib/agent/llm.ts`의 `structured()`)로 호출. `LLM_BASE_URL`만 바꾸면 Groq·OpenAI로도 동작.
- 무료 등급 유의사항: Gemini API 무료 등급은 입력·출력이 Google의 서비스 개선에 쓰일 수 있고 민감·개인 정보를 넣지 말라고 안내한다 ([Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms)). 그래서 안내 메일은 마스킹 후 보내고, 시연·평가 데이터는 전부 가상으로 만들었다.

## 2. 외부 데이터·API

- 공공데이터포털 잡알리오 공공기관 채용정보 (data.go.kr/data/15050508) — 추천 후보 (키 발급 후 연동, 현재는 가상 공고)
- 한국산업인력공단 국가자격 시험일정 (공공데이터포털 오픈API) — 자격증 일정 (키 발급 후 연동, 현재는 직접 입력)
- 평가·시연 데이터: 팀이 만든 가상 공고 30건, 가상 안내 메일 20건, 충돌 시나리오 10건 (`eval/`). 실존 개인정보 없음. 실제 기업명은 '시연용 가상' 표시.

## 3. 개발·기획 과정의 생성형 AI

| 도구 | 쓴 곳 | 사람이 직접 한 일 |
|---|---|---|
| Claude (Claude Code) | 코드 작성·테스트 작성·리팩터링, PR 정리 | 기능 범위·우선순위 결정, 코드 리뷰와 머지, 로컬 실행 확인 |
| Claude | 기획 구체화, 경쟁 서비스·통계 조사 보조, 소개서 구성·디자인 초안 | 서비스 방향 결정, 통계 원문 대조, 최종 문구 확정 |
| ChatGPT (Codex) | 코드 초안·디버깅 보조 | 채택 여부 판단 |

평가셋 정답은 생성 스크립트(`web/scripts/gen-eval.ts`) 한 스펙에서 원문과 같이 만들고, 팀이 표본을 직접 읽어 확인했다.

## 4. 역할

- 강재준(대표): PM, Agent API·프롬프트·출력 스키마 설계
- 김세헌: 웹 캘린더·크롬 확장 구현
- 이영은: 공공데이터 연동, 평가셋 구축·측정, 화면 설계
