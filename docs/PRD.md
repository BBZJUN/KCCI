# 잡도리 PRD (MVP)

## 한 줄
공고 하나 수락하면, 최종 발표까지의 전형 일정을 AI 에이전트가 대신 챙겨 주는 취준 캘린더.

## 대상 사용자
- 주요: 여러 기업 전형을 동시에 진행하며 자격증 시험·아르바이트 등 개인 일정도 함께 관리하는 취업·이직 준비생
- 페르소나: 개발 직군 취준생 민지(26) — 동시 진행 6곳(신한은행·토스뱅크·삼성전자·SK하이닉스·현대자동차·구글), 12월 자격증 시험, 주 2회 아르바이트

## 이용 흐름 (Happy Path)
1. 관심 직무·지역 설정
2. 추천 공고 확인 후 수락 (또는 크롬 확장으로 지금 보는 공고 담기)
3. 전형 일정 자동 생성 — 확정 실선 / 범위 점선 / 추정 점점선, 단계마다 원문 근거
4. 결과 메일·문자 업로드 → 다음 전형 확정(점선→실선) 또는 불합격 시 이후 일정 정리
5. 충돌 경고 확인 → 조정 (개인 일정 이동 제안, 기업 문의 문구 제안)

## 화면 (소개서 07의 목업과 동일하게)
### ① 오늘의 추천 공고
- 카드: 기업 이니셜 배지, 기업명, 공고명, 마감 D-day
- 추천 이유 체크리스트 3개 (관심 직무 일치 / 일정 여유 / 보유 자격 우대)
- 전형 단계 요약 한 줄, 버튼 [수락하고 전형 일정 만들기] [관심 없음]

### ② 전형 일정 확인 · 원문 근거
- 단계별 행: 왼쪽 세로선(실선/점선/점점선), 단계명, 날짜, 신뢰도 배지(확정/범위/추정), 근거 문장(이탤릭)
- `evidence_missing`이면 '근거 확인 필요' 빨간 표시
- 버튼 [N개 일정 캘린더에 추가] [직접 수정] — 추가 전까지 DB에 쓰지 않음

### ③ 안내 메일 반영
- 메일/문자 붙여넣기(또는 캡처 업로드, P1) → 판독 결과
- 변경 diff: 점선 카드 '예상 1차 면접 12/16~19' → 실선 카드 '1차 면접 12/18 14:00'
- 버튼 [확정 일정으로 반영] [무시]

### 메인: 월간 캘린더 (소개서 05)
- 기업별 색, 신뢰도별 선 스타일, 현재 진행 전형은 굵은 테두리
- 충돌 날짜에 빨간 ! 배지 + 하단 경고 바 (예: '12/17 현대자동차 1차 면접(확정) ↔ 신한은행 1차 면접(추정)')
- 개인·자격증 일정 직접 추가

## 시연 시나리오 (3분 영상, 필수 제출물 04)
1. 추천 공고(신한은행) 수락 → 전형 4단계 생성
2. 원문 근거 확인 후 캘린더 추가
3. 토스뱅크 합격 메일 업로드 → 점선이 실선으로
4. 현대자동차 면접 확정 → 신한은행 추정 면접과 충돌 경고·조정 제안

## 성공 지표 (소개서 08)
| 지표 | 방법 | 목표 |
|---|---|---|
| 일정 등록 시간 | 공고 1건 전형 일정을 캘린더에 옮기는 시간 (수동 vs 자동) | 1분 이내 |
| 전형 추출 정확도 | 가상 공고 30건 단계·날짜·유형 일치율 | 90%+ |
| 결과 반영·충돌 탐지 | 메일 20건 판독 정확도 / 충돌 10건 경고율 | 90% / 100% |

## 범위 밖 (MVP)
실제 메일함 연동(OAuth), 민간 플랫폼 크롤링, 모바일 앱, 결제.
